Idle Speed: Specifications

Idle 500 to 900 rpm

Idle speed is controlled by the Powertrain Control Module (PCM) through the Idle Air Control (IAC) Motor, and is not adjustable.

CAUTION: This vehicle is equipped with a factory adjuste4d throttle plate position set screw. Never attempt to adjust idle speed using this screw, unless directed to do so in a service procedure.
