Ambient Light Sensor/VTA Set Lamp

AMBIENT LIGHT SENSOR/VTA SET LAMP
The ambient light sensor is a photo diode in combination with a light emitting diode for the vehicle theft alarm set lamp. The sensor/indicator will be used for the Auto Headlamp Feature and the Vehicle Theft Alarm set/armed diagnostic indicator.
