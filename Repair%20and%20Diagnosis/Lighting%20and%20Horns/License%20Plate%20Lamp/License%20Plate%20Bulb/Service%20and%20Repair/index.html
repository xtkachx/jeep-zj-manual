License Plate Bulb: Service and Repair

REMOVAL
1. Remove screws attaching license plate lamp to license plate housing.
2. Separate lamp from housing.
3. Grasp bulb and pull from bulb socket.

INSTALLATION
1. Position bulb in socket and press into place.
2. Position license plate lamp in license plate housing.
3. Install screws attaching license plate lamp to license plate housing.
