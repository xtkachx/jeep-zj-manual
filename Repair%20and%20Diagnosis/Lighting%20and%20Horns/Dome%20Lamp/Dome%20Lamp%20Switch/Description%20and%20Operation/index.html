Dome Lamp Switch: Description and Operation

I/P DIMMER/DOME LAMP SWITCH
This switch is located near the rotary headlamp switch. It has a slide control which is used to adjust the intensity of the instrument panel lighting. Instrument panel dome lamps can be requested by sliding the I/P illumination slide control past the detent in the slide mechanism (full right).
