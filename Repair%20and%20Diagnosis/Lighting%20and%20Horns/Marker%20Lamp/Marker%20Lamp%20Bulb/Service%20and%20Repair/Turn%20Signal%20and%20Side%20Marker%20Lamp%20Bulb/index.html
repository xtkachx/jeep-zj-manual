Turn Signal and Side Marker Lamp Bulb

REMOVAL
1. Remove parking lamp.
2. Remove turn signal/side marker lamp.
3. Rotate turn signal bulb socket counter clockwise, press in on bulb and rotate 1/4 turn to remove.
4. Rotate sidemarker bulb socket counter clockwise grasp and pull from lamp.

INSTALLATION
1. Install side marker lamp bulb.
2. Install turn signal lamp bulb.
3. Install turn signal/side marker lamp.
4. Install parking lamp.
