Door Courtesy Lamp

REMOVAL
1. Remove door trim panel.
2. Remove bulb socket from lamp.
3. Depress lamp locking tabs and separate lamp from trim panel.

INSTALLATION
1. Position lamp in trim panel and snap into place.
2. Install bulb socket in lamp.
3. Install door trim panel.
