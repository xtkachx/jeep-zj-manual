Door Courtesy Lamp Bulb

REMOVAL
1. Remove door trim panel.
2. Remove bulb socket from lamp.
3. Pull bulb from socket.

INSTALLATION
1. Position bulb in socket and press into place.
2. Install bulb socket in lamp.
3. Install door trim panel.
