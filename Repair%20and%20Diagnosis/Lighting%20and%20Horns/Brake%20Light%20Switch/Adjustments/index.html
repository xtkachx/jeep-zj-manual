Brake Light Switch: Adjustments



1. Press and hold brake pedal in applied position.
2. Pull switch plunger all the way out to fully extended position.
3. Release brake pedal. Then pull pedal fully rearward. Pedal will set plunger to correct position as pedal pushes plunger into switch body. Switch will make racheting sound as it self adjusts.
