RKE Programming

To program the Remote Keyless Entry (RKE) transmitter access codes into the RKE receiver in the Passenger Door Module (PDM) requires the use of the "Chrysler Diagnostic Readout Box" (DRB) scan tool. Chrysler DOES NOT provide a procedure for programming the RKE transmitter without the DRB scan tool. For testing of the RKE system, refer to Power Door Lock System With Remote Keyless Entry in Diagnostic Charts under Body Control Module Testing and Inspection Procedures. Testing and Inspection
