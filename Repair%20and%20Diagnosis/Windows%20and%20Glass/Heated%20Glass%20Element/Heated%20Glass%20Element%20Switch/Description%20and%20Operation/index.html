Heated Glass Element Switch: Description and Operation

SYSTEM OPERATION
The rear window defogger switch is mounted in the inboard instrument panel switch pod, inboard of the steering column. The momentary-type switch provides a hard-wired ground signal to the Body Control Module (BCM) each time it is depressed. The BCM rear window defogger timer and logic circuitry responds by energizing or de-energizing the rear window defogger relay.

Energizing the rear window defogger relay provides electrical current to the rear window defogger grid and the Light-Emitting Diode (LED) in the switch, which lights to indicate that the defogger system is turned on. The defogger switch and LED cannot be repaired. If faulty, the inboard switch pod unit must be replaced.
