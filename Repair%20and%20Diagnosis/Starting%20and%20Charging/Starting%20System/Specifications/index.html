Starting System: Specifications

Power Rating 1.4 Kilowatts
Voltage 12 Volts
Number of Fields 4
Number of Poles 4
Number of Brushes 4
Drive Type Planetary Gear Reduction
Free Running Test Voltage 11.2 Volts
Free Running Test Max Amp Draw 80 Amperes
Free Running Test Minimum Speed 2,500 RPM
Solenoid Closing Maximum Voltage 7.8 Volts
