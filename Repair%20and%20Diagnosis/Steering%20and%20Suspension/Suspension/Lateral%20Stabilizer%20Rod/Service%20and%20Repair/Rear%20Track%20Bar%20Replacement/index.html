Rear Track Bar Replacement






REMOVAL
1. Raise and support the vehicle.
2. Remove the bolt and nut from the frame rail bracket.
3. Remove the bolt from the axle tube bracket. Remove the track bar.

INSTALLATION
1. Install the track bar to the axle bracket and install a new bolt.
2. It may be necessary to pry the axle assembly over to install the track bar. Install the track bar to the frame rail bracket. Loosely install the bolt and flag nut.
3. Remove the supports and lower the vehicle.
4. Tighten the track bar bolts 100 Nm (74 ft. lbs.).
