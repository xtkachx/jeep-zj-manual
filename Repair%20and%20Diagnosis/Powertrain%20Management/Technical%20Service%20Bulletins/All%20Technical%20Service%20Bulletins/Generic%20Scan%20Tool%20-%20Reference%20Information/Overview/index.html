NOTE:
THIS BULLETIN APPLIES TO ALL VEHICLES WITH OBDII (ON-BOARD DIAGNOSTICS, 2ND GENERATION) AND COMPETITIVE MAKES WITH OBD.

DISCUSSION:

Generic Scan Tool (GST), Publication No. 81-170-00008, is being provided with this Technical Service Bulletin to provide reference information when using Generic Scan Tool on OBDII vehicles.

The Chrysler Group's Generic Scan Tool support was released in 1997 and until DRBIII(R) Release 50.00 (June, 2000) resided within each software release of DRBIII(R) Standalone code. Since release 50.00 Generic Scan Tool support software has migrated to the SuperCard2 PCMCIA card part number CH8361. This software has been updated. Additional support has been added.

Additional copies of the GST publication, 81-170-00008, can be ordered from DDS Distribution Services, LTD. Their number is 1-800-890-4038.

CH8361 SuperCard2, Release 7.00 (or higher)
