Repair Procedure: Overview

This bulletin involves installing a cold weather by-pass kit to the transmission cooler circuit, selectively erasing and reprogramming the Powertrain Control Module (PCM) with new software (calibration changes for 1996 models only), and using the DRB III to selectively turn off the overdrive inhibitor feature for all applications.

NOTE:
IT IS ESSENTIAL THAT THE TRANSMISSION COOLER BYPASS KIT BE INSTALLED PRIOR TO DISABLING THE INHIBITOR FEATURE. TRANSMISSION DAMAGE MAY OCCUR IF THE BYPASS KIT IS NOT INSTALLED.

NOTE:
EVEN WITH BYPASS KIT INSTALLATION AND THE INHIBITOR FEATURE TURNED OFF, 4TH GEAR WILL BE INHIBITED UNTIL THE OIL SUMP TEMPERATURE REACHES 0 C (30 F). THIS MAY TAKE SEVERAL MINUTES.
