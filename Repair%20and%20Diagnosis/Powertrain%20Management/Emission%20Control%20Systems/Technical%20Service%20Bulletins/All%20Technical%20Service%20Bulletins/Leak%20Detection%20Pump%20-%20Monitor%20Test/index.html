Leak Detection Pump - Monitor Test

NUMBER: 18-12-99

GROUP: Vehicle Performance

DATE: June 18, 1999

MAY 2, 1997, WHICH SHOULD BE REMOVED FROM YOUR FILES AND NOTED IN
THE 1997 TECHNICAL SERVICE BULLETIN MANUAL (PUBLICATION NO. 81-699-98004). THIS IS A COMPLETE REVISION AND NO ASTERISKS HAVE BEEN USED TO HIGHLIGHT REVISIONS.

SUBJECT:
DRB III(R) Leak Detection Pump (LDP) Monitor Test.

OVERVIEW:

This bulletin explains the operation and application of the LDP - MONITOR TEST.

MODELS:

1997 - 1999 (AB) Ram Van
1997 - 1999 (AN) Dakota
1997 - 1999 (BR/BE) Ram Truck
1998 - 1999 (DN) Durango
1997 - 1999 (FJ) Avenger/Sebring
1997 - 1999 (JA) Cirrus/Stratus/Breeze
1997 - 1999 (JX) Sebring Convertible
1997 - 1999 (LH) Intrepid/Concorde/Vision/LHS/300M
1996 - 1999 (NS) Town & Country/Caravan/Voyager
1997 - 1999 (PL) Neon
1997 - 1999 (PR) Prowler
1997 - 1999 (SR) Viper/Viper Coupe
1997 - 1999 (TJ) Wrangler
1999 (WJ) Grand Cherokee
1997 - 1999 (XJ) Cherokee
1997 - 1998 (ZJ) Grand Cherokee

NOTE:
THIS INFORMATION APPLIES TO VEHICLES EQUIPPED WITH A LEAK DETECTION PUMP (LDP).

DISCUSSION:
The original test (LDP Dealer Test Mode) functionality was eliminated in the DRB III(R). A new test has been released (LDP-MONITOR TEST) and is now incorporated into the Powertrain Control Module (PCM) software. The DRB III(R) can actuate this test by sending simple commands to the PCM.

Most new model (1999) vehicles were released with this test capability. Older models may require a flash update to make this test available. Most of the older model software has been released.

The best way to determine if the test is available is to connect the DRB III(R) and attempt to run the LDP Monitor Test found under ENGINE SYSTEM TESTS.

If the DRB III(R) does not show the test on the screen, or if a message appears - LDP Monitor Test NOT Supported by PCM, it means the vehicle will require a flash update to make the test available. As mentioned earlier, most of the software with this feature has been released. If a flash update is not available and the vehicle is LDP equipped, standard LDP leak test procedures as listed in the applicable diagnostic publications will have to be performed until the software becomes available.

As a reminder, the LDP MONITOR TEST should only be used to reproduce leak faults and verify repairs that have been made to the evaporative system.

EQUIPMENT REQUIRED:

1 CH6OOO Scan Tool (DRB III(R))
1 CH7035 General Purpose Interface Bus Cable (GPIB)
1 CH7OOO/7001 J1962 Cable
1 CH7O1O J1962 MMC Cable
AR(1) CH8361 Super Card 2

TEST PROCEDURE:

1. Connect the DRB Ill (scan tool) to the vehicle and power it up.

2. From the MAIN MENU, select DRB III(R) standalone.

3. From the STAND-ALONE MAIN MENU, select 1998 - 2000 Diagnostics.

NOTE:
FOR EARLIER MODELS, SUPERCARD 2 MUST BE USED FOR DIAGNOSIS.

4. From the SELECT SYSTEM screen, select ENGINE.

5. Press enter twice to go to the SELECT FUNCTION screen.

6. From the SELECT FUNCTION screen, select Engine System Test.

7. From the ENGINE SYSTEM TEST screen, select LDP Monitor Test.

8. Once in the LDP Monitor Test, the DRB Ill� will prompt the operator for the remaining test sequence.
