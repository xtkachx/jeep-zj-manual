Output Shaft Speed Sensor

OUTPUT SHAFT SPEED SENSOR-PCM INPUT

This sensor generates a signal to the Powertrain Control Module (PCM) relating to the speed of the transmission main drive shaft. This input is used with 4-speed electronic transmissions only.
