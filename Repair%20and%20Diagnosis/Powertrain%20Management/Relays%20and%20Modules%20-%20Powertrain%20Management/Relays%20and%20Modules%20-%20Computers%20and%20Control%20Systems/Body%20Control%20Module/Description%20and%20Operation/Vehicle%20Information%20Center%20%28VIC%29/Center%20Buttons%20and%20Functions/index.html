Center Buttons and Functions

VEHICLE INFORMATION CENTER BUTTONS AND FUNCTIONS

SET
After the ignition has been turned on and the service reminder has been displayed, pressing the SET button for at least two seconds will initiate the time/date setting mode. Pressing SELECT momentarily and then holding SET for two or more seconds will reset the service reminder message.

Pressing SET while turning on the ignition will place the VIC in the set up mode that contains all the user changeable setting.

SELECT
If the time/date has been set, pressing the SELECT and SET simultaneously while turning the ignition on will prompt the VIC to display the module version for five seconds or until the SET or SELECT button is pressed.

VERSION
Displays the module version level. Press the SET and SELECT button while turning the ignition to display the module version.
