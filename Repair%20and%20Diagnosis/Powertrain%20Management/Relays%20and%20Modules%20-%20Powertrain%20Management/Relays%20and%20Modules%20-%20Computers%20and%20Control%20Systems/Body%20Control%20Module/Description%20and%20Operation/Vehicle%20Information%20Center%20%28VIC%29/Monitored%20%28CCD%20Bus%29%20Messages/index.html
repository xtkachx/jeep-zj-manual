Monitored (CCD Bus) Messages

THE VEHICLE INFORMATION CENTER MONITORED (CCD BUS MESSAGES)

CHECK BATTERY:
The message will be displayed if the PCM detects a low or high battery voltage and the PCM sends the corresponding CCD bus message to the VIC. There is no icon for this message and it is displayed for the duration of the problem.

DOOR AJAR MESSAGES
The BCM monitors all door switches and broadcasts a CCD bus status message to the VIC. If a door is opened or closed the VIC responds by changing the appropriate icon and message. The door icons and messages will not update it the VIC cannot detect the bus message. If the car is moving at critical speed and any door, liftgate, or hood is open, the appropriate message and icon will be displayed. The VIC will suppress the time and date and display only the appropriate door ajar message. A beep request will be generated when critical speed is reached for the first time. All the door icons consist of two segments. A closed segment displayed as blue/green and an open or ajar segment displayed in red.

TRANS OVERTEMP
The message will be displayed if the PCM determines that the transmission is overheating and broadcast the corresponding CCD bus message. There is no icon for this message and it is displayed for the duration of the problem.

US or METRIC
The VIC monitors a CCD bus message, from the BCM, to synchronize the display format with overhead console US/METRIC button selection.
