Description of Vehicle Information Center

VEHICLE INFORMATION CENTER
The Vehicle Information System (VIC) is located below the radio in the center stack. The VIC consists of a multicolored vacuum fluorescent (VF) display with a vehicle outline and Two Buttons. The VIC receives input from the CCD bus and hard-wired circuits. In response to these inputs the VIC displays information in the form of alphanumeric, graphical icon, and chime alert request to the Body Control Module (BCM). In the normal mode the VIC will display icons and alphanumeric messages in a choice of five different languages. The customer preference display functions are set in the setup mode using the "SET" and "SELECT" buttons. There are four types of VIC warnings and messages, monitor hard wired circuits, monitored CCD bus messages, transfer case shifter position, and chime requests. The VIC messages are displayed in the order of their priority. Normal mode for the VIC is defined as ignition on, the service reminder not showing, and the time date set.

The VIC clock is synchronized by a CCD bus message from the radio to display the same time (hours and minutes) as the Radio clock. IF the voltage is removed from the VIC, the time and date start flashing and default to 12:00am Sun Jan 1, 12 hour mode or 0:00 Sun 1 Jan, 24 hour mode. No other messages will be displayed until the time and date are set. Use the "SET" and "SELECT" buttons to set the time and date, change the language, or service reminder.

All VIC messages including DTC's are active codes and will be erased as soon as the condition is corrected. The Diagnostic Trouble Code (DTC) are identified by an asterisk (*) and are addressable via the DRB.
