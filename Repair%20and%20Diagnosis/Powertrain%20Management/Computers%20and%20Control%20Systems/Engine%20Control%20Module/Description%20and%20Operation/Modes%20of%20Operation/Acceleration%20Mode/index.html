Acceleration Mode

ACCELERATION MODE

This is an Open Loop mode. The Powertrain Control Module (PCM) recognizes an abrupt increase in throttle position or Manifold Absolute Pressure (MAP) pressure as a demand for increased engine output and vehicle acceleration. The PCM increases injector pulse width in response to increased throttle opening.
