Malfunction Indicator (Check Engine) Lamp

MALFUNCTION INDICATOR (CHECK ENGINE) LAMP-PCM OUTPUT

The malfunction indicator lamp illuminates each time the ignition key is turned on. It will stay on for approximately three seconds as a bulb test. The lamp is displayed on the instrument panel as the CHECK ENGINE lamp.

If the Powertrain Control Module (PCM) receives an incorrect signal, or no signal from certain sensors or emission related systems, the lamp is turned on. This is a warning that the PCM has recorded a system or sensor malfunction. In some cases, when a problem is declared, the PCM will go into a limp-in mode. This is an attempt to keep the system operating. It signals an immediate need for service.

The lamp can also be used to display a Diagnostic Trouble Code (DTC). Cycle the ignition switch On-Off-On-Off-On within three seconds and any codes stored in the PCM memory will be displayed. This is done in a series of flashes representing digits.

The lamp is also used to indicate certain engine misfires.
