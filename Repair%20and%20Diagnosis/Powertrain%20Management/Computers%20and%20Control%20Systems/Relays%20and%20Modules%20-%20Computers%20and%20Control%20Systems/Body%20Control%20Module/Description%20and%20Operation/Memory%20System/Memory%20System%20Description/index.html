Memory System Description

MEMORY SYSTEM
An optional memory system is available. The memory features include a 10 position driver's seat, outside mirrors, and radio presets. Up to two different memory settings are available. Either memory profile can be selected via the door mounted memory select switches or the keyless entry transmitter. The radio will allow 10 AM and 10 FM presets to be stored for driver 1 and the same for driver 2. If driver 1 enters the vehicle with the Remote Keyless Entry (RKE) or pushes the memory switch 1, then decides to listen to driver 2 radio stations, this can be accomplished by pushing the memory switch 2 when the vehicle is above 15 MPH. This will select driver 2 radio stations but will leave mirror and seat position unaffected. If the entire memory system is inoperative, see Memory Seat Test 1A.
