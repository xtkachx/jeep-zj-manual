Memory Seat

MEMORY SEAT
This optional feature allows up to two different driver seat positions to be set and automatically recalled upon demand. The seat can be repositioned to position 1 or 2 via the remote keyless entry transmitter or the door mounted memory switches. The set procedures are as follows: 1) Move the seat to desired location. 2) Depress the Memory Set switch. An indicator on the Set switch will illuminate and flash to indicate the system is in the set mode. 3) Depress either the 1 or 2 switch. The flashing Set indicator will go out to indicate that the set has been achieved. A CCD message is sent to the Memory Seat Module identifying current seat position as memory set 1 or 2 (via seat position potentiometer values).

To recall established Set Positions: Either unlock the doors via the remote keyless entry transmitter or push a memory switch button. The door module recognizes the transmitter as being either #1 or #2 and sends a CCD message to the Memory Seat Module asking for the seat to be moved to the position established for #1 or #2. If during a Memory Recall cycle, the driver attempts to move the seat, the Memory Recall function is aborted and the seat will move to the desired location. Memory recall will be inhibited when either the driver's seat belt is buckled, or the vehicle is in motion (15 mph). Also pulling the belt out of the retractor will stop the memory seat.

Heated seats are optionally available. A relay module located under each front seat controls the heat level based on I/P mounted switch. Two levels of heat are available (low and high).
