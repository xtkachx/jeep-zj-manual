Multiplex Door Modules

DOOR MODULES
A new feature introduced is the multiplex door module. One of these modules is located in each front door. They control the following features: power door locks, driver window express down, memory recall functions (memory seats and mirrors), keyless entry and power mirrors. Reduced wiring complexity is a key feature of using multiplexed door modules. These modules are addressable with the DRB from the Body menu to facilitate faster and easier diagnosis.
