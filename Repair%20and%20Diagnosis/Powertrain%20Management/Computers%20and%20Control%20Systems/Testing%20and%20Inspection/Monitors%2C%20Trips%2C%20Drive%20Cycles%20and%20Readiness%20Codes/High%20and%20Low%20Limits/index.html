High and Low Limits

DESCRIPTION
The Powertrain Control Module (PCM) compares input signal voltages from each input device. It will establish high and low limits that are programmed into it for that device. If the input voltage is not within specifications, and other fault criteria are met, a fault will be stored in memory. Other fault code criteria might include engine rpm limits or input voltages from other sensors or switches. The other inputs might have to be sensed by the controller when it senses a high or low input voltage from the control system device in question.
