State Display Tests

STATE DISPLAY TEST MODE

Fig. 1 DLC Location:




The switch inputs to the Powertrain Control Module (PCM) have two recognized states; HIGH and LOW. For this reason, the PCM cannot recognize the difference between a selected switch position versus an open circuit, a short circuit, or a defective switch. If the State Display screen shows the change from HIGH to LOW or LOW to HIGH, assume the entire switch circuit to the PCM functions properly. Connect the DRB scan tool to the data link connector (Fig. 1) and access the state display screen. Then access either State Display Inputs and Outputs or State Display Sensors.
