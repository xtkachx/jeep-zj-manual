Heater Core: Service and Repair


Fig.59 Heater Core:





REMOVAL
1. Remove the heater-A/C unit from the vehicle. "Housing Assembly HVAC : Service and Repair" Service and Repair
2. Remove the heater core retaining screws.
3. Pull the heater core straight out of the housing.

INSTALLATION
1. Install the heater core into the housing.
2. Position the clips over the heater core tubes. Install and tighten the screws.
3. Install the heater-A/C unit into the vehicle.
Under "Housing Assembly HVAC : Service and Repair" Service and Repair
