Body Control Module - Check Sum Error Fault

NO: 08-31-96

GROUP: Electrical

DATE: Sept. 27, 1996

SUBJECT:
Body Control Module - Check Sum Error Fault

MODELS:
1997 (ZJ) Grand Cherokee

NOTE:
THIS BULLETIN APPLIES TO VEHICLES BUILT PRIOR TO AUG. 5, 1996 (MDH 08-05-XX).

DISCUSSION:

A check sum error code may be displayed by the DRB III or MDS when requesting Body Control Module Diagnostic Trouble Codes (DTC's). This a normal condition on vehicles built prior to 8/5/96. The fault is a result from a programming change, made to eliminate a conflict between the auto-headlamp, auto parade/funeral (full bright) mode and the headlamp "ON" with wiper feature. The auto parade/funeral mode activates the instrument panel lights to full bright for day light operation with the headlights on. The error will only be displayed when DTC's are requested with the DRB Ill or MDS and is not visible to owners. The "check sum error" DTC should be ignored on these vehicles if encountered. Also, the instrument panel display auto parade/funeral mode will not be activated with the auto headlamp "ON" with wiper feature.
