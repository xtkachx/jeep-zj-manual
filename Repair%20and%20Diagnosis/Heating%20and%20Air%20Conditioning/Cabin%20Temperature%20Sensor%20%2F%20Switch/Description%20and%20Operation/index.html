Cabin Temperature Sensor / Switch: Description and Operation

CIRCUIT OPERATION
The in-car temperature sensor is a variable resistor. Circuit C10 provides the in-car temperature sensor signal to the ATC module. Circuit D41 provides ground for the sensor. Circuit D41 connects to the ATC module.
