Introduction

The ATC controller is designed with on-board diagnostics which is capable of troubleshooting each input and output circuit of the controller. When a fault is detected and in memory, an "Er" is momentarily displayed on the control panel. This will happen only once during an ignition cycle.

There are three different groups of testing features that control panel is capable of:
1. Fault Codes
2. Input circuit testing
3. Output circuit testing/Actuator tests
