Restriction In System


CAUTION: Never add R-12 to a system designed to use R-134a. Damage to the system will result.

1. Discharge the A/C system into a recovery/recycle device.
Refrigerant Recovery
2. Replace the condenser-to-evaporator line (liquid line).
3. Evacuate the A/C system.
Refrigerant System Evacuate
4. Charge the A/C system with 1.75 lbs. (28 oz.) of R-134a refrigerant.
Refrigerant System Charge
