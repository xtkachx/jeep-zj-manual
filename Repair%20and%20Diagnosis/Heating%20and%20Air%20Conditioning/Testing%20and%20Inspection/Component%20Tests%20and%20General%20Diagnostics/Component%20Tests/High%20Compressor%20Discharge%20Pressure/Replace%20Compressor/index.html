Replace Compressor

CAUTION: Never add R-12 to a system designed to use R-134a. Damage to the system will result.

1. Discharge the A/C system into a recovery/recycle device.
2. Remove the compressor.
Service and Repair
3. Install a new 10PA17 (R-134a refrigerant-type) compressor.
4. Replace the condenser-to-evaporator line (liquid line).
5. Evacuate the A/C system.
Refrigerant System Evacuate
6. Charge the A/C system with 1.75 lbs. (28 oz.) of R-134a refrigerant.
Refrigerant System Charge
