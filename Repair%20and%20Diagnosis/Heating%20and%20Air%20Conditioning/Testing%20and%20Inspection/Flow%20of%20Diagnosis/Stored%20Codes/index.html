Stored Codes



A stored code indicates that there was an active code present at some time. The reason for the active code was corrected and the code was changed to a stored code.


If the reason for the code was corrected, the Automatic Temperature Control (ATC) head will erase the code after 72 key cycles. The code may also be erased from the head using the front panel controls or the DRB III.


If no obvious problems are found, read active codes on the DRB while wiggling the harness and connectors. Recheck for codes periodically as you work through the system. This procedure may uncover a malfunction that is difficult to locate.
