Active Codes



An active trouble code indicates an on-going malfunction. The defect is present every time the Automatic Temperature Control (ATC) head checks the circuit or function. It is not possible to erase an active code. Active codes will change to stored once the reason for the code has been corrected.


If an active code is present, the temperature display on the ATC head will display an "ER" for 5 seconds during the key on check, the display will then revert to temperature readings.
