A/C - Cycles to OFF When Ignition Is Turned OFF

NO: 24-07-97

GROUP: Heating & A/C

DATE: May 9, 1997

SUBJECT:
A/C Cycles to "OFF" When the Ignition Key Is Turned Off

MODELS:
1997 (ZJ) Grand Cherokee
1997 (ZG) Grand Cherokee (International Markets)

SYMPTOM/CONDITION:

Vehicles equipped with Automatic Temperature Control (ATC), operating in the manual mode, may cycle out of the A/C mode when the ignition switch is turned off.

DIAGNOSIS:

Operate the system in the manual mode, with the A/C on and turn the ignition switch off. If the system does not start in the A/C mode when the vehicle is restarted, perform the Repair Procedure.

PARTS REQUIRED:

1 55116065 Control Module - ATC

REPAIR PROCEDURE:

This bulletin involves replacing the ATC control with a recalibrated unit.

1. Record the preset radio stations, disconnect and isolate the battery negative cable.

2. Remove the right switch pod bezel by gently prying it out with a trim stick or suitable tool.

3. Remove the ATC control module screws. Pull the control module out of the instrument panel and disconnect the electrical connectors.

NOTE:
THE ATC CONTROL MODULE MUST BE OF THE LATEST DESIGN. PRIOR TO INSTALLING THE CONTROL MODULE, INSPECT THE TAG LOCATED ON THE PART. THE SERIAL NUMBER ON THE PARTS TAG MUST BE 0109293 OR HIGHER. DO NOT USE A CONTROL MODULE BUILT PRIOR TO THIS SERIAL NUMBER. PARTS BUILT PRIOR TO THIS SERIAL NUMBER SHOULD BE RETURNED USING THE MATERIAL RETURN AUTHORIZATION (MRA) PROCEDURE.

5. Install the new control.

6. Install the switch pod bezel.

7. Set the radio stations and clock.

POLICY: Reimbursable within the provisions of the warranty.

TIME ALLOWANCE:
Labor Operation No: 24-75-01-91 0.5 Hrs.

FAILURE CODE: P8 - New Part
