Coupling Disconnect

Fig.6 Spring Lock Coupling Disconnect:





1. Discharge the refrigerant from the system using a recovery/recycling device.
2. Fit the appropriate Spring Lock Coupling Tool from A/C Tool Kit 6125.
3. Close the tool and push into the open side of the cage to expand garter spring and release female fitting.
The garter spring may not release if the tool is cocked while pushing it into the cage opening.
4. After garter spring is expanded, pull fittings apart within the tool.
5. Remove the tool from the disconnected coupling.
6. Separate the two ends of the coupling.
