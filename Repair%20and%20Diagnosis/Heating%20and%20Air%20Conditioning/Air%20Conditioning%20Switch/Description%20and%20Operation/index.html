Air Conditioning Switch: Description and Operation

CIRCUIT OPERATION
If the vehicle is equipped with Automatic Temperature Control (ATC), the Automatic Temperature Control Module sends the A/C select switch to the Body Control Module (BCM) on circuit C90. If the vehicle has manual A/C, the A/C - heater control switch sends the A/C select signal to the BCM on circuit C90.
