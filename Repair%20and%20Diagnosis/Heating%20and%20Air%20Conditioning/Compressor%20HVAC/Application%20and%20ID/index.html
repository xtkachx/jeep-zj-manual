Compressor HVAC: Application and ID



The A/C system uses a 10PA17 fixed displacement compressor. A label identifying the use of R-134a refrigerant is located on the compressor.

CAUTION: DO NOT use an R-12 compressor on an R-134a system. The systems are not compatible.
