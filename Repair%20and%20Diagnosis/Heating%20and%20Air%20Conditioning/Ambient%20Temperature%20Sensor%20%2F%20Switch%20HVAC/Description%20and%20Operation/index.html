Ambient Temperature Sensor / Switch HVAC: Description and Operation

CIRCUIT OPERATION
The ambient temperature sensor is a variable resistor. Circuit C8 provides the ambient temperature sensor signal to the ATC module. Circuit D41 provides ground for the sensor. Circuit D41 connects to the ATC module.

As ambient (outside) temperature varies, the resistance in the sensor changes. Circuit C8 from the Body Control Module (BCM) supplies power to the sensor. Circuit D41 provides the sensor signal to the BCM.
