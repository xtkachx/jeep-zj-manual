Manual A/C-Heater

CIRCUIT OPERATION
The A/C-Heater control head contains a blend door position sensor. The sensor is a variable resistor that provides the blend door position input to the blend door motor actuator on circuit C36.

Circuit F71 from fuse 12 in the junction block powers the actuator when the ignition switch is in the RUN position. Circuit C34 splices to connect the blend door actuator to ground circuit Z1.
