Mode Door Actuator

CIRCUIT OPERATION
Circuit C40 from the Automatic Temperature Control (ATC) module supplies 5 Volts to the position switch in the mode door motor. The ATC module receives the sensor signal from the mode door motor on circuit C39. Circuit D41 provides ground for the mode door position sensor. Circuit D41 connects to the ATC module.

The ATC module operates the mode door motor on circuits C37 and C38.
