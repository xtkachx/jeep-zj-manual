Push Button Module

REMOVAL
1. Remove the overhead console as described.
2. Unplug the wire harness connectors from the push button module.
3. Remove the four screws (long-type console) or two screws (short-type console) that secure the push button module to the console housing.
4. Remove the push button module from the console.
5. Reverse the removal procedures to install.
