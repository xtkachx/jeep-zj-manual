Overhead Console Sunglasses Storage Bin

SYSTEM OPERATION
A sunglasses storage bin is included in the long-type overhead console. The interior of the bin is covered with a flocking material to protect the sunglasses from being scratched. This bin features a push/push-type latching mechanism, and a viscous dampening system for a fluid opening action.
