Power Windows

POWER WINDOWS
The power windows can be raised or lowered from the driver's door module (DDM) or the individual door switch. The DDM has a lock out switch that prevents the windows from being operated from any switch except the driver's door. When this switch is pressed, it also shuts off the individual door switch LED's.

A new feature of this system allows the windows to be operated from any window switch for 30 seconds after the ignition switch is turned off, provided a front door is not opened. Another feature is the `Express Down'. When the driver presses the down switch to the second detent, the window will travel all the way down even if the switch is released. To stop the window, simply press the switch momentarily in either direction.

On the rear window motor circuit there is 12 volts provided on both the up and down circuits. This 12 volts is supplied by the appropriate door module. When the rear switch is pressed, the supply circuit to one side of the switch is opened and ground is provided making a complete circuit.
