Headlamps on With Wipers

HEADLAMPS ON WITH WIPERS
If the vehicle contains the optional auto headlamps feature, an additional feature is available. This feature automatically turns on the headlamps if the wipers are activated. This occurs only if the auto head lamps are in the automatic mode. This feature is programmable by the dealer via the DRB service tool.
