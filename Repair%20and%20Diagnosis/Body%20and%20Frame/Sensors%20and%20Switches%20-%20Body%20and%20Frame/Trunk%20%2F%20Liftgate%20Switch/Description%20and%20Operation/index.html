Trunk / Liftgate Switch: Description and Operation

CIRCUIT OPERATION
When closed, the liftgate disable switch provides signal to the Body Control Module (BCM) on circuit M4 indicating a request to disable the courtesy lamps. To operate, all the doors must be closed with only the liftgate open. Pushing on the liftgate lens activates the switch. Pushing on the Lens a second time deactivates the switch.

After receiving the courtesy lamp disable signal, the BCM turns off the courtesy lamps by de-energizing the courtesy lamp relay.

When the courtesy lamp disable switch closes, it provides battery voltage to the (BCM) on circuit M4.
