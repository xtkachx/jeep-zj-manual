Heating and A/C



The ATC system is capable of storing and displaying all of the following codes:


- Mode Door Travel Range Too Small
- Mode Door Travel Range Too Large
- Blend Door Travel Range Too Small
- Blend Door Travel Range Too Large
- Calibration Checksum Error
- BCM Message Missing
- PCM Message Missing
- CPU Checksum Error
- In-Car Temp Sensor Circuit Open
- Solar Sensor Circuit Open
- Panel Mode Control Circuit Open
- Blend Door Feedback Circuit Open
- Mode Door Feedback Circuit Open
- In-Car Temp Sensor Circuit Shorted
- Solar Sensor Circuit Shorted
- Panel Mode Control Circuit Shorted
- Panel Lamp Input Error
- Blend Door Feedback Circuit Shorted
- Mode Door Feedback Circuit Shorted
- Mode Door Not Responding
- Blend Door Not Responding
