Test 12A - Controller Failure

Test 12A:





Related Figures:






NAME OF CODE:
Controller Failure

WHEN MONITORED:
Ignition on.

SET CONDITION:
The Controller Antilock Brake (CAB) monitors its own internal microprocessors for proper operation. If an error occurs, the trouble code is set. If this code appears, the CAB should be replaced.

POSSIBLE CAUSES:
- High resistance in the CAB ground circuit.
- Interference from RFI/EMI
- Improperly installed cellular phones or radio transmitters
- Interference from high tension power lines
- Failed CAB
- Internal open or short valve circuit, solenoid coil, or valve driver.
- Internal circuit or connection failure.

NOTE:
- A single asterisk (*) in the diagnostic chart indicates the Verification Test must be performed.


- A double asterisk (**) in the diagnostic chart indicates a connector must be checked, then cleaned or repaired as necessary.
