Front Cable Replacement

REMOVAL
1. Release parking brakes.
2. Disconnect battery negative cable and raise vehicle on hoist.

Parking Brake Equalizer:





3. Remove front cable adjusting nut and disengage cable tensioner from equalizer. Then remove front cable from tensioner.
4. Disengage front cable from insert and insert from floorpan.
5. Lower vehicle.
6. Remove console.
7. Remove park brake lever.
8. Disconnect front cable from parking brake lever and remove cable.

INSTALLATION
1. Connect front cable to lever assembly.
2. Seat front cable in floor pan.
3. Install lever assembly.
4. Install console.
5. Raise vehicle.
6. Assemble front cable, cable tensioner and equalizer.
7. Adjust parking brake system if a new cable, or tensioner has been installed, or if tensioner mechanism has been loosened, or removed for access to other components. Adjustments
8. Lower vehicle.
9. Connect battery negative cable.
