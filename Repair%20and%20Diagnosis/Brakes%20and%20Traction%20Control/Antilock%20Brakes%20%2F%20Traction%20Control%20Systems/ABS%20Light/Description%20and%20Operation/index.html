ABS Light: Description and Operation

ABS WARNING LAMP

The amber ABS warning lamp is located in the instrument cluster. It is used to inform the driver that the antilock function has been turned off due to a system malfunction. The lamp illuminates at start-up to perform a self check. The lamp goes out when the self check program determines the system is operating normally. If an ABS component exhibits a fault, the CAB will illuminate the lamp and register a trouble code in the microprocessor. The lamp is controlled indirectly by the CAB. The instrument cluster inverts the lamp signal. The CAB grounds the circuit to turn off the lamp.

BRAKE WARNING LAMP

The red brake warning lamp is located in the instrument cluster. It can be activated by application of the parking brake, a leak in the front or rear wheel brake hydraulic circuit, or by turning the ignition switch to the start position.
